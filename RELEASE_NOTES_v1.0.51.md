# TINDA POS v1.0.51 — Free Community Lounge, Red Unread Alerts & Multi-Platform Support

**Release Date:** October 4, 2026  
**Version:** 1.0.51  
**Build Type:** Stable Production Release

---

## What's New in v1.0.51

### 1. 100% Free Nationwide Merchant Community Lounge
- **Universal Messaging:** Real-time messaging in the TINDA Global Lounge is now **completely free for all merchants** (both Free and VIP Pro tiers). Any store owner or cashier can participate, share wholesale supplier deals, discuss inventory practices, and collaborate with peers nationwide.
- **Verified Developer Identity:** Ian's **👑 Ian (Founder / Dev) [VERIFIED]** badge remains strictly protected at the edge via cryptographic master key validation to protect stores against impersonation.

### 2. Dynamic Red Pulse Unread Alert Beacon
- When the chat drawer is closed, a lightweight, non-blocking background heartbeat monitors for new incoming merchant messages.
- The floating **Global Lounge** trigger button automatically transitions from standard indigo to a **glowing red alert** (`bg-gradient-to-r from-red-600 to-rose-600`, pulsing glow, and white blinking beacon with a `NEW` badge) as soon as an unread message arrives.
- Opening the chat immediately clears the notification and returns the button to its normal resting state.

### 3. Clean POS Header Toolbar
- Removed the unclickable `+ add · F2 qty` informational text label from the top navigation bar, eliminating clutter and streamlining cashier counter workflows.

### 4. Official Linux AppImage Release
- Alongside the Windows NSIS Installer and Portable Edition, TINDA POS now officially distributes a standalone **Linux AppImage** (`TindaPOS-1.0.51.AppImage`) with native Wayland support (`xwayland: 0`) and bundled SQLite binaries (`linux-x64.node`).

### 5. English System Modals
- All update dialogs, notifications, and prompts are 100% in professional English (`New Update Available`, `Later`, `Download Update`, `Restart & Install`).
