==============================================
 TINDA POS  -  Windows Customer Release
 Software Version: 1.0.0
==============================================

THANK YOU for choosing TINDA POS, an offline Point-of-Sale system for
sari-sari stores and small businesses.

--------------------------------------------------------------
 QUICK START (3 simple steps)
--------------------------------------------------------------
1) RUN THE INSTALLER
   - Double-click  TindaPOS-Setup-1.0.0.exe
   - Click "Install" and follow the on-screen steps.
   - TINDA POS is installed; it will open automatically after install.

   (Prefer a portable version? Use  TindaPOS-Portable-1.0.0.exe
    instead - no install needed, just run the file.)

2) COMPLETE STORE SETUP (first time only)
   - On first open, the Store Setup screen appears.
   - Enter your store name, phone/address, and create an Admin
     account (username, password, and a 4-digit PIN).
   - Click Finish.

3) START SELLING
   - Add products (Inventory page) and start selling from the POS page.
   - Create backups regularly (Backup page).

--------------------------------------------------------------
 IMPORTANT: WORKS FULLY OFFLINE
--------------------------------------------------------------
TINDA POS works completely offline. NO internet connection is
required for normal store operation. All your data - products,
sales, customers, utang, expenses, and backups - stays on YOUR
computer.

--------------------------------------------------------------
 WHERE YOUR DATA IS STORED / KEPT SAFE
--------------------------------------------------------------
Your business data (the database, backups, receipts, and exports)
is stored OUTSIDE the program folder, under:

    C:\Users\<your Windows user>\AppData\Roaming\TINDA POS\

Because data is kept separate from the app, INSTALLING A NEW VERSION
or UNINSTALLING does NOT delete your store data.

TIP: Keep a copy of this whole "TINDA POS" user-data folder somewhere
safe (another drive, USB, or cloud) as an extra backup.

--------------------------------------------------------------
 GETTING HELP
--------------------------------------------------------------
- See TindaPOS-User-Guide.pdf for the full manual.
- Need a receipt printer or USB barcode scanner? Both work with
  standard Windows devices - no special drivers are required. If no
  printer is installed, the POS still works normally.
