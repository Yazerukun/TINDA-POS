Mga lods! TINDA POS v1.0.2 is a free, offline-first desktop POS made for sari-sari stores and small businesses in the Philippines. Walang subscription at tuloy ang benta kahit walang internet. Local sa inyong computer ang main database; optional lang ang backup copy to a folder managed by OneDrive, Google Drive for Desktop, or Dropbox.

========================================
DATA SAFETY
========================================

Default Windows database:
%APPDATA%\TINDA POS\database\tindapos.db

Installer and Portable intentionally use the same AppData database. Kapag nilipat o ni-rename ang Portable EXE, hindi ito gagawa ng bagong database. Huwag manually burahin ang AppData database para lang mag-update.

Before upgrading from v1.0.1:
1. Gumawa muna ng Backup Now.
2. Install/run v1.0.2 using the same Windows account and data profile.
3. The data should remain preserved because it is separate from the program files.

The complete v1.0.1 → v1.0.2 upgrade test will be performed during final release validation; it is not yet claimed as passed.

========================================
FAQ
========================================

Q: Offline ba talaga?
A: Oo. Local ang checkout, inventory, customers, utang, expenses, at reports. Optional lang ang synced-folder backup.

Q: Saan naka-save ang data?
A: Sa %APPDATA%\TINDA POS. Separate ito sa installed program files.

Q: Safe ba ang Restore at Reset?
A: May validation, integrity check, at safety backup. Exact RESET confirmation at authorized account ang kailangan para sa reset.

Q: Pwede ang barcode scanner?
A: Oo. Standard USB barcode scanners work like keyboard input.
