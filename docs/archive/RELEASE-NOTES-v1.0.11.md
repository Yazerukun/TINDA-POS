# TINDA POS v1.0.11

- Fixed dashboard net sales not deducting refunds.
- Dashboard refreshes on sales, refunds, voids, window focus, and a 15-second fallback.
- Dashboard follows the local calendar date; daily totals are retained after Z-Read.
- Improved 58mm/80mm sales receipt, X-Read, Z-Read, and Cash Count layouts.
- Z-Read prints saved actual cash, closing time, and over/short status.

Software Update uses the same GitHub provider and installer settings. No database migration.
Install using Settings > About > Software Update > Check for Updates.
